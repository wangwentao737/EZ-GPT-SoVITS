# EZ-GPT-SoVITS

EZ-GPT-SoVITS 是使用本地 GPT-SoVITS 整合包的中文 Windows 语音工作台。

## 快速入门

1. 将 Windows x64 便携 ZIP 完整解压到可写目录，双击 `EZ-GPT-SoVITS.exe`。准备好目标整合包 GPT-SoVITS-v5-20261006。
2. 进入「设置 → 添加启动路径」，选择整合包目录里的 `go-webui.bat`。引擎运行时会在该整合包目录中写入运行文件。
3. 回到「工作台」，选择要检查的模型家族，点击「检查资源」。如果报告有缺项，按提示补齐文件，再选中失败项点击「复查所选项」。

更换整合包后，可在「设置 → 引擎详情」按模型家族查看功能状态，并使用已有声音试合成一句。任务中的引擎指纹变化时，该功能会重新等待验证。

### 已有模型，合成台词

1. 在工作台点击「使用已有模型」，然后点击「导入声音」。
2. 选择同一个声音的 GPT `.ckpt` 和 SoVITS `.pth` 权重，填写模型家族和名称。选一段约 3 至 10 秒的清晰参考音频，填写音频里的原话及参考语言，再选择默认台词语言。可以先点击「试听参考音频」。
3. 点击「保存声音」。选中它，输入一句台词，点击「生成语音」。EZ 会启动所需的引擎服务，生成后会启用「播放」「另存 WAV」和「所在目录」。

成功试音后，可以在「声音与素材」查看验证所用的引擎、时间、参数和文件 SHA-256。更换引擎，或检测到权重、参考音频和对应文本发生变化时，按界面提示再生成一次即可重新验证。早期版本仅保存引擎路径的声音也可以重新试音。

勾选「每行生成一条音频」可查看有效台词条数并提交批量任务，空行会自动跳过。同一批次相邻的同声音台词可复用加载好的模型，每句仍有独立任务和 WAV。点击「查看本批任务」可按原台词顺序查看每条结果，取消本批排队项，或把失败和中断的条目提交为新的重试批次。

「高级参数」中可调整切句、语速、种子和采样参数，也可保存为当前声音的默认值。从「任务记录」右键选「复用合成参数」可恢复已提交的设置。

在合成页点击「文本转为台词表」，可把编辑区的有效行追加到台词表。为所选行指定声音并调整顺序后，可以提交整表，也可以修改某句再点「只重做所选」。旧修订的 WAV 仍可在任务记录中查看。

台词表支持按行号导出 `001_角色.wav`，也可按指定停顿合并为 48 kHz、单声道、16 位 PCM WAV。导出前会提示尚无当前修订成品的行和同名文件。任务记录支持按批次筛选和翻页。

### 只有录音，训练声音

1. 在工作台点击「用录音训练声音」，新建项目。填写项目名和说话人，按素材选择语言，并选定模型家族。
2. 点击「导入原始录音」，再点「切片」。已有合格的 WAV 片段时，可使用「导入已切片录音」。
3. 普通话录音可用「中文自动转写」。也可以导入已有标注，或双击「文本」列填写。逐条对照录音校对。选中一行可试听，右键可编辑或排除片段。
4. 点击「准备数据」，校对后的标注会一并保存。数据准备完成后，选择显卡、批量和轮数，点击「开始训练」。训练页和窗口底部会显示当前阶段与已用时间。自动转写显示已处理的片段数。支持逐轮保存的 v5turbo 训练显示已保存权重的轮次。
5. 两阶段完成后，选中一条清晰的参考片段并点「试听并入库」。保存声音后，在「语音合成」输入短句试音。

训练中断后重新打开项目。适配版本的检查点通过校验且显卡、批量和轮数一致时，可以点击「从检查点继续」。也可用「开始训练」重跑当前阶段。

补录时可追加或替换最近一批。核对导入预览后再应用，已有切片的校对会保留，新片段标为待校对。导入标注会显示唯一匹配、缺标片段、找不到音频、重复和格式错误等差异。可勾选「只看待校对」和「循环试听」，用空格播放或暂停，用 Ctrl+Enter 保存所选校对并跳到下一条。

### 查找文件与处理错误

- 数据保存在 EXE 同级的 `data`，默认成品位置为 `data/outputs`。搬迁前退出程序，再复制便携目录及其 `data`。出现素材库迁移预览时，展开详情核对旧路径和缺失文件。应用会在新数据目录备份索引，并另存路径发生变化的标注。旧标注和旧位置的副本可留作恢复依据。
- 在「设置」更改成品目录只影响随后提交的任务。搬迁自定义成品目录或引擎后，在同一页选择「重新定位成品」或「重新定位引擎」。如训练项目提示重新准备数据，请先核对标注并准备数据。已入库声音可以重新试合成。
- 「声音与素材」可以按类型、项目或声音筛选，查看关联任务和文件位置。表格左键选中整行，右键可查看当前能执行的操作。
- 试听片段时可以切换耳机或扬声器，也可右键选「用系统播放器打开」。合成失败可在「任务记录」查看原因，修复后重试。
- 启动报告端口冲突时，先退出占用端口的旧引擎，再从 EZ 启动。目标整合包的主服务使用 9874，快速推理服务使用 9872。
- 「工作台 → 导出诊断」可预览、复制报告，并选择是否包含日志。针对一条历史任务，可右键选「导出所选任务诊断」。

## 构建

需要 Windows x64、Visual Studio 2022 的 C++ 桌面开发工作负载、CMake 3.24 或更新版本，以及 Qt 6.8.3 MSVC 2022 x64。Qt 安装需包含 Qt Multimedia。

在项目目录运行以下命令，将 Qt 路径替换为实际安装位置。

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 "-DCMAKE_PREFIX_PATH=C:/Qt/6.8.3/msvc2022_64"
cmake --build build --config Release --parallel
cmake --install build --config Release --prefix (Join-Path $PWD "out/portable")
```

开发联调可以通过 `--data-root` 指定独立的数据目录。引擎副本、测试样本、Qt 开发依赖及发行产物均由 Git 忽略。开发联调使用独立的引擎副本，原始安装只用于只读核对。

## 回归测试

运行 `pwsh -File tests/portable-smoke.ps1` 验证便携启动、SQLite 初始化、端口冲突与目录联接拒绝。运行时需让 9874 端口空闲，以便脚本创建临时监听器。

如开发机安装了 Python，也可运行 `python -B tests/task-recovery.py`。该脚本通过便携 EXE 验证归档提交和训练阶段的重启恢复，测试数据写入项目的 `.test` 目录。

保留 v0.1.20 便携包后，可运行 `python -X utf8 -B tests/workspace-migration.py --portable out/portable` 验证搬迁、外部成品和索引回滚。加 `--live` 可用独立引擎副本重新合成搬迁后的声音。

如已在 `.test` 中备好独立引擎和引擎联调样例，可运行 `python -X utf8 -B tests/live-cancellation.py` 验证运行中取消和后续任务续跑。脚本的 `--help` 列出样例路径选项。

同一套夹具可用 `python -X utf8 -B tests/resource-preflight.py` 验证缺少启动资源、接口变化和损坏权重的处理，以及失败后的真实合成。

`python -X utf8 -B tests/training-integrity.py` 使用独立引擎实测预处理、样本错配拦截、两阶段训练和新权重试听。`python -X utf8 -B tests/training-resume.py` 验证 v5turbo 的 GPT 和 SoVITS 在完成一轮后中断、恢复，以及配置不匹配时的拦截。

批内复用基准和推理退出测试见 `tests/batch-inference.py --help`，万条历史查询见 `tests/history-paging.py --help`。构建时启用 `-DEZ_BUILD_CHECKS=ON` 可生成 `EZ-component-checks.exe`。在 Qt 运行库和插件可用的环境中传入独立测试目录，可验证录音追加、键盘校对、台词修订和混合采样率导出。
