# 20261006 兼容清单基线验收

测试环境为 Windows x64、Qt 6.8.3、RTX 4070 Laptop GPU。EZ 使用以 `88c9ed4` 为基础的 0.1.21 兼容清单开发构建。测试通过独立整合包副本和隔离的 EZ 数据目录运行。20261006 的脚本 SHA-256 记录在 [兼容清单](registry-v1.json)。引擎运行指纹为 `fbd25020b46119a09b4d9a5e8a7558e94156bcbe05b18cc724281346ebb0590e`。

<a id="startup"></a>

## 启动

历史 0.1.16 桌面验收通过 EZ 启动原生 BAT，并检查主服务与推理服务的进程归属。2026-11-25 重新通过兼容清单启用该构建，使用默认端口 9874 和 9872，Gradio 报告 4.44.1。

同目录名的另一构建、目录改名、修改 BAT 和端口的判定采用组件夹具验证。BAT 摘要为采集参考。主服务脚本用于匹配构建，快速推理脚本用于核对合成范围。端口和 Gradio 版本用于连接及诊断。

## 切片与转写

历史独立样本使用含中文、空格及括号的数据路径，从 EZ 完成切片，用本地 Paraformer、VAD 和标点模型生成普通话 UTF-8 标注。粤语登记为尚未验证。

2026-11-25 的回归用同一份普通话原录音生成两段切片，并核对两条转写均有文本。切片任务为 `b7a2ea7f-1bda-4456-b879-dda9a556d1d7`，转写任务为 `6ffc97ac-b2fd-477c-9a75-f7183511ef9f`。

历史 20261006 样本用 8 条软件生成的录音从 EZ 准备数据，分别得到 SoVITS 和 GPT 权重，并用两份新权重完成试听。

2026-11-25 的全新训练回归用 8 条 v5turbo 样本再次准备数据。缺失特征、重复语义索引和已变更的标注均被拦截。SoVITS 任务 `eb45d1cd-9b54-467f-a57e-111c4afaf764` 与 GPT 任务 `54b564db-7660-401d-85ff-f18f2a8f03bf` 各自从头完成两轮，产生新权重。新权重试音任务 `78e3fe2a-0ae3-45e5-a741-360144c85633` 归档了 3.48 秒 WAV，SHA-256 为 `007ab02213afac372ed01447f183c356c495c2b5feb3a77673694b704cbb59f2`。

<a id="legacy-interface"></a>

## 0725-cu124 接口差异

历史原生测试通过 0725-cu124 自身的 WebUI 使用 v2、v2Pro 和 v2ProPlus 生成 WAV。该包也报告 Gradio 4.44.1，并且 BAT 摘要与 20261006 一致。它的主服务和快速推理脚本摘要与 20261006 不同。

基于[既有 v2 接口快照](../tests/fixtures/0725-cu124-inference.json)核对。0725 快速推理有 21 项入参，20261006 适配器要求 23 项。把 23 项中的同类型参数交换顺序也会让 20261006 适配器在发送推理调用前拒绝。后续增加了独立的 [0725-cu124 适配与验收](acceptance-0725-cu124.md)。

后续整合包在拿到真实样本后按[登记模板](registration-template.md)验证。模拟接口用于验证筛选、诊断、更新回退和队列切换。

## 清单与队列回归

- 同名目录独立判定。改名、修改启动 BAT 和主服务端口后仍可匹配同一构建。更新某项调用的脚本或运行接口时，撤下对应能力。
- 合成专用夹具在训练家族列表为空。移走和补齐 v2Pro 扬声器模型时，v2 仍可选，详情给出 v2Pro 缺失资源路径。
- 首次离线及损坏缓存使用内置清单。导入较新修订后可立即查看新选项，重开后沿用该修订。重复导入返回已是最新，网络连接失败或导入损坏文件时保留上次可用修订。
- 两套模拟整合包在同一持久化队列依次启动。旧任务保留提交时的整合包和家族，两个任务都在发现切片接口变化后拦截。
- 基线验收时，GitHub `main` 尚未提供清单，已核对 HTTP 404 时的回退行为。便携构建可以通过内置或离线清单运行。
