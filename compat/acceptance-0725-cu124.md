# 0725-cu124 合成适配验收

<a id="startup"></a>

## 启动与识别

样本使用 [兼容清单](registry-v1.json) 中登记的主服务脚本与快速推理脚本摘要。原生 BAT 的摘要与 20261006 相同。主服务的四个合成控制事件签名与 20261006 一致。联调在保留原始脚本的独立整合包副本中运行。

2026-11-25，Windows x64、RTX 4070 Laptop GPU、EZ 0.1.21 兼容开发构建。EZ 用副本的原生 BAT 启动并核对监听进程，Gradio 报告 4.44.1。原安装目录用于读取和比对脚本摘要。

## 合成

## 与 20261006 切换

同一 EZ 持久化队列依次执行 0725-cu124 的 v2 和 20261006 的 v5turbo，两个整合包均使用默认端口 9874 和 9872。两条任务分别保留原启动路径与适配器并完成归档。任务号为 `64c039a5-e223-44a3-b4f7-f62d615a2c5a` 和 `67b8a6a9-fb7d-462a-8e07-93c1f1e82188`。另一次独立回归验证了 20261006 的 v5turbo、v2、v2Pro 和 v2ProPlus 四个家族，归档摘要均与基线一致。
