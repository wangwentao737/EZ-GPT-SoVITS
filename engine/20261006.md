# 20261006 引擎契约

EZ 使用 Windows 整合包自带的 `go-webui.bat` 启动主进程，工作目录为该脚本所在目录。主服务在 9874，快速推理服务在 9872。实测主服务报告 Gradio 4.44.1，安装包内含 gradio_client 1.3.0。

`engine/bridge.py` 记录具体参数顺序及已知的资源路径。推理先把声音资产添加到该模型家族的权重候选目录，再调用快速推理服务。一个任务内独占整个加载和合成过程。音频通过 Gradio 文件接口返回，经解码验证后由桌面端归档。

整合包的 WebUI 转写会走命令行脚本的默认模型，普通话默认会触发 Fun-ASR-Nano 下载。EZ 对普通话转写直接加载已安装的 Paraformer、VAD 和标点模型。资源缺失时可以导入标注。

检测到整合包的 ONNX Runtime GPU 1.18.0 时，EZ 在启动脚本所属的子进程中移除 `CUDA_PATH`。当该组件缺少与其兼容的 CUDA 或 cuDNN 库时，普通话注音模型 G2PW 可以回退到 CPU。PyTorch 仍使用整合包自带的 CUDA 运行库。

## 已取得的联调结果

- 在独立整合包上通过原生 BAT 启动并识别主服务。
- 使用 v5turbo 基础权重和合成参考录音生成 3.48 秒 WAV，实际种子为 42。
- 从 8 条测试录音准备训练数据，以批量 1、训练 2 轮分别得到 v5turbo SoVITS 和 GPT 权重。使用这对新权重生成 4.48 秒 WAV，实际种子为 42。
- 在包含中文、空格及括号的数据目录中生成切片并完成训练数据准备。
- 使用本地普通话模型识别两个切片，生成可以校对和训练的 UTF-8 标注。
- 通过持久化队列交替提交基础模型与新训练模型的任务，SQLite 均记录成功，两份归档 WAV 均可解码。
- 使用只包含 Windows 系统目录的 PATH 启动部署后的便携 EXE。
- 重启恢复回归覆盖已完成归档、发布前中断、同大小但内容已变化的 WAV、旧版截断 WAV，以及 SoVITS 已成功但 GPT 尚未完成的项目。回归通过便携 EXE 打开测试数据库，核对产物索引、项目阶段和历史任务快照。
- 实时取消回归等待独立引擎真正创建切片、SoVITS 训练或快速推理子进程后再取消。三项均停止目标子进程，后续合成均产生可校验的 WAV。取消推理后，测试还核对当前任务的临时权重已清理。
- 资源回归验证缺少内置 Python 时启动脚本不会运行。用本机模拟服务删除合成接口时，合成任务被拦截，主服务仍能启动，切片接口仍被识别。
- 在真实引擎中依次提交缺参考音频、SoVITS 权重截断、成品目录被文件占用、第二份权重加载失败及正常合成。前三项在模型加载前被拦截，第四项检测到推理子进程提前退出，最后一项正常归档可核对摘要的 WAV。

联调使用的软件生成录音、权重副本和日志保存在 Git 忽略的测试目录。

## 0.1.16 便携版验收

验收使用 Windows 11、本地 Release x64 ZIP 和项目内独立引擎副本。另用同版本 Qt 界面组件驱动两条完整工作流。测试目录包含中文、空格和括号。

| 验收项 | 已验证的结果 |
|---|---|
| 解包与首次启动 | 用仅含 Windows 系统目录的 PATH 启动，初始化 SQLite。端口占用时保留原监听进程，经目录联接选择的引擎路径会被拦截。 |
| 已有模型 | 在设置中添加引擎，导入 GPT、SoVITS 权重和参考录音，输入台词后合成。播放器进度正常推进，导出的 WAV 与归档文件逐字节一致。 |
| 从录音训练 | 导入原始录音，执行切片、普通话转写、试听与保存标注、准备数据。两阶段训练完成后，使用新权重入库、合成、播放和导出。 |
| 重启与历史 | 从 ZIP 解包的桌面程序重新打开测试数据，识别已保存的引擎路径并显示两条工作流的七条成功记录。从新训练声音的合成任务右键复用，恢复所选预设、语言和原台词，重新生成并归档了 2.44 秒的 WAV。退出应用后，引擎端口释放。 |
| 旧模型权重 | 使用 20261006 独立整合包加载两套 v5turbo 权重，以及 v2、v2Pro、v2ProPlus 配套权重。五项任务均生成非静音 WAV，归档位置和 SHA-256 与各自的任务记录一致。该结果适用于在当前引擎中加载这些权重。 |
| 取消与恢复 | 切片、SoVITS 训练和快速推理均在子进程实际运行后测试取消，每次后续合成均正常归档。重启恢复覆盖已归档成品、截断文件和已完成的训练阶段。 |
| 资源耗尽提示 | 在隔离模拟环境中给任务工作进程注入 CUDA 显存不足和系统写入空间不足错误。训练提示降低批量，合成提示释放显存或更改生成目录。三条失败任务均无成品索引，后续切片正常完成。模拟测试验证错误处理及队列行为。 |
| 浏览器与接口 | 模拟引擎验证主进程和推理子进程继承静默浏览器命令。真实引擎在同版程序中完成合成。缺少合成接口时，切片能力仍可用。 |

干净的 Windows 10/11 x64 环境需要独立验收。首次使用者自行通过界面完成两条工作流的人工验收，以及旧整合包自身的运行能力，也需分别测试。

## 训练数据和重跑规则

准备数据时逐样本对照标注、文本索引和语义索引，检查 32 kHz 音频和 HuBERT 特征。普通话另检查 BERT 特征，v2Pro 系列另检查说话人特征。通过校验后才记录样本数量和标注摘要。正式训练前会再次校验。

EZ 为每次 SoVITS 或 GPT 训练分配独立实验目录，任务目录里的 `training-run.json` 记录训练参数、数据集和检查点路径。重跑当前阶段会从新的实验目录开始。

20261006 中经过适配的 v5turbo 训练支持从检查点继续。EZ 对照 WebUI 和训练器摘要，为这一版本的 SoVITS 和 GPT 每轮保存检查点。恢复时重新核对标注、预处理产物、底模、训练配置和参数，再把原检查点复制到新实验。GPT 副本内的输出目录以字符串保存，使引擎可以用默认的安全加载模式读取。任务只接受训练器明确确认恢复且完成目标轮次后生成的权重。其他版本继续支持按阶段重跑。
